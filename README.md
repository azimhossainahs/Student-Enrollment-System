# Student Enrollment System with Waitlist

A console-based Student Enrollment System developed in C. The project provides basic course management, student enrollment, employee management, and waitlist functionality using file-based data storage.

## Features

### Course Management

* Add new courses
* View available courses
* Delete courses
* Set maximum enrollment capacity
* Track current enrollment

### Student Enrollment

* Enroll students in available courses
* Check course capacity
* Add students to a waitlist when a course is full

### Waitlist Management

* Maintain a first-come, first-served (FIFO) waitlist
* Process students from the waitlist when seats become available

### Employee Management

* Add employees
* View employee information
* Delete employees
* Basic employee authentication

### Data Persistence

* Store course information using binary file handling
* Store employee information using binary file handling
* Store student and waitlist information using text files

## Waitlist Flow

When a course reaches its maximum capacity:

```text
Student attempts enrollment
          ↓
   Is the course full?
      ↙          ↘
    No            Yes
    ↓              ↓
 Enrolled       Waitlisted
                   ↓
          Seat becomes available
                   ↓
          Waitlist is processed
                   ↓
       First student is enrolled
```

The waitlist is processed in FIFO (First In, First Out) order.

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/azimhossainahs/StudentEnrollmentSystem-with-waitlist-.git
```

### 2. Navigate to the project directory

```bash
cd StudentEnrollmentSystem-with-waitlist-
```

### 3. Compile the program

```bash
gcc main.c -o enrollment_system
```

### 4. Run

```bash
./enrollment_system
```

## Current Limitations

This is a learning project and has some limitations:

* Uses file-based storage instead of a database
* Input validation can be improved
* Duplicate enrollment/waitlist validation can be improved
* Student unenrollment functionality is limited
* Authentication is basic and not suitable for production use
